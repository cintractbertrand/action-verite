# Règles d'économie de jetons

## Réponses
- Réponds directement, sans préambule ni reformulation de ma demande.
- Réponses courtes par défaut ; détaille seulement si je le demande.
- Pas de récapitulatif final des étapes déjà faites.

## Fichiers et code
- Pour une modification, montre uniquement les passages changés, jamais le fichier complet réécrit.
- Utilise Edit pour les changements ciblés ; Write seulement pour créer un fichier ou le remplacer entièrement.
- Lis seulement les parties utiles d'un fichier (offset/limit) ; ne relis pas un fichier que tu viens de modifier.
- Utilise Grep/Glob avant d'ouvrir des fichiers au hasard.
- Ne liste pas et ne parcours pas l'arborescence sans nécessité.

## Outils et agents
- Ne lance pas de recherche web, de sous-agent ou d'outil lourd sans nécessité.
- Regroupe les appels d'outils indépendants dans un même tour.
- Modèle : Haiku par défaut ; Sonnet ou Opus seulement si la tâche est complexe.

## Dialogue
- Si ma demande est ambiguë, pose une seule question de clarification avant de produire.
- Si la conversation devient longue, propose un résumé de l'état du travail pour repartir sur une session neuve (/clear ou /compact).
